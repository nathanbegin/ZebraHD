3. Code-barres

EAN-13 / UPC-A : les zéros devant sont ajoutés automatiquement pour compléter 12 (ou 11) chiffres ; « Chiffres (zéros) » est alors ignoré.

4. Impression

La largeur du papier (perpendiculaire au sens d'impression) reste fixe. Seule la longueur, parallèle à la sortie de l'imprimante, est ajustée au contenu + marges, puis le couteau coupe.
Dans la fenêtre d'impression : choisir l'imprimante Zebra, le papier de même taille que l'étiquette, marges « Aucune » et échelle 100 %.
Configuration de l'imprimante (pilote ZDesigner ZD420 300 dpi)
  1. Options : unité cm, portrait, Largeur et Hauteur = taille du type d'étiquette (ex. 7,62 × 5,08 cm = 3" × 2"), zones non imprimables à 0.
  2. Réglages avancés → Mode opératoire : Massicot (coupé par lot de 1) pour couper après chaque étiquette.
  3. Type de support : Transfert thermique pour le papier non autocollant avec ruban ; Thermique direct pour des étiquettes thermiques sans ruban.
  4. Mode de détection : Continu pour un rouleau coupé au couteau (obligatoire avec la longueur automatique) ; Détection Web pour des étiquettes à espaces ; Marque pour des repères noirs. Puis Calibrer.
  5. Ajustement (En haut / À gauche) : laisser à 0 ; le décalage de l'application suffit pour centrer.
  6. Tramage : essayer « Aucun » pour des barres et du texte bien nets.
  7. Dans Chrome : même papier que le pilote, marges « Aucune », échelle 100 %, sans en-têtes ni pieds de page.
Les « polices de code à barres » du pilote (Code 128, Code 39, EAN) ne sont pas utilisées : l'application dessine elle-même les barres.

⚙ Réglages

Apparence

Offset de rotation du contenu

S'ajoute à la rotation du contenu choisie dans « 2. Texte ». Appliqué à l'impression seulement : l'aperçu montre le résultat voulu. Sert à compenser l'orientation du pilote. Avec la longueur automatique, préférez 0° ou 180°.

Décalage manuel du contenu (centrage)

Mêmes axes que l'aperçu (X = sens d'impression, Y = largeur du ruban). Réglage propre à cet ordinateur.

Précision d'impression (codes-barres)

Chaque barre fine occupe alors un nombre entier de points : les barres ont toutes la même largeur et le scan est plus fiable. Le code peut devenir un peu plus étroit.

Calibrage du centrage

1. Choisissez le papier voulu, puis imprimez l'étiquette de calibrage (cadre à 3 mm des bords, sans décalage appliqué). 2. Mesurez avec une règle l'écart entre le cadre et chaque bord de l'étiquette. 3. Entrez les valeurs : le décalage X/Y est calculé et appliqué.
